Security

We welcome responsible reports that help protect Notin users.

Report privately

Email security@notin.app with the affected URL, reproducible steps, impact and any supporting material. Do not include another person’s note content, credentials or tokens unless strictly necessary.

Safe-harbor expectations

Use test accounts and the minimum data required. Do not use denial of service, social engineering, persistence, destructive actions, automated mass scanning or access to data beyond what proves the issue. Allow reasonable time for investigation before disclosure.

Current security model

  • HTTPS is required in production.
  • Access tokens are short lived and refresh sessions rotate.
  • Notes are account-scoped and public shares use revocable secret links.
  • Notin is not end-to-end encrypted.
  • Production AI features may send bounded note content to the configured provider when invoked.

Response targets

The operator should acknowledge valid reports within three business days and provide status updates for high-severity issues. These targets must be staffed before public launch.
